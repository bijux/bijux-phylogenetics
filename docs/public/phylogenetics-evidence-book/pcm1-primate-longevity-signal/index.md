# PCM1: Primate Longevity Signal

PCM1 is the study family built from the Lund lecture material on plots and
phylogenetic signal. In this repository it has been decomposed into smaller
evidence units that track the path from data preparation to comparative signal
and ancestral outputs.

## What PCM1 Covers

PCM1 is the repository's introductory comparative trust study. It follows one
governed path from data and tree preparation into signal and ancestral review,
with the goal of making the early comparative assumptions visible rather than
implicit.

## What PCM1 Is Good For

- understanding the basic tree-and-trait preparation path
- checking that early comparative steps behave consistently across R and Bijux
- teaching what must be true before signal or ancestral results should be
  trusted

## Read PCM1 In Order

1. [data and tree preparation](data-and-tree-preparation.md)
2. [signal and ancestral results](signal-and-ancestral-results.md)

That order matters. PCM1 is intentionally structured so the preparation state
is visible before the later comparative claims.

## What PCM1 Does Not Prove

- it does not close every comparative method in the repository
- it does not turn one primate teaching family into one general claim about all
  datasets
- it does not replace the broader evidence-book freshness, integrity, or
  coverage reports
