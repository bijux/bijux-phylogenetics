# PCM2 Signal Diagnostics And Open Boundaries

PCM2 also does something important for credibility: it keeps its open edges
visible.

The governed slices cover:

- phylogenetic signal testing
- residual and diagnostic review surfaces
- ancestral reconstruction comparisons
- explicit handling of the remaining intercept-mode likelihood sweep boundary

That last point matters. A useful evidence-book is not only a place where
agreement is documented. It is also where the repository says plainly what is
still incomplete.

## What This Part Answers

- which signal and diagnostic surfaces remain trustworthy enough to discuss
- which comparative edges are still explicitly bounded or open
- how the study separates strong comparative evidence from still-incomplete
  intercept or sweep boundaries

## Reading Rule

PCM2 should be read as one deeper bounded trust study, not as one blanket claim
that comparative model criticism in the repository is already complete. Its
open boundaries are part of the study's value, not an embarrassment to hide.
