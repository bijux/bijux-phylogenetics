# PCM5 Runtime Reference Mapping

No governed repository surface currently reproduces the central `MCMCglmm`
PGLMM workflows from PCM5.

Relevant nearby repository surfaces exist, but they are narrower:

- reviewer-facing phylogenetic logistic approximations for binary comparative
  regression
- comparative regression model-selection ledgers
- tree-linked comparative reporting and residual review surfaces

Those surfaces do not replace the lecture's posterior mixed-model workflow.
They do not provide:

- Poisson phylogenetic mixed-model posteriors
- multinomial mixed-model posteriors
- posterior-derived ancestral node effects
- probability-scale transformations of posterior slope distributions
- multi-random-effect variance partitions equivalent to the lecture

This dossier makes that boundary explicit so PCM5 is documented and deployed as
source-backed evidence scope, not over-claimed as present-day repository
parity.
