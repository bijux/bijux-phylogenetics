# PCM2 Runtime Reference Mapping

PCM2 already owns a governed parity program for baseline GLS, Pagel-lambda
regression, transformed-tree review, evolutionary-mode fitting, and signal
diagnostics across the primate lecture family.

Checked-in reference artifacts:

- `primate_pgls_and_signal_reference_r.R`
- `reference_results.json`

Relevant owned surfaces include:

- baseline GLS and phylogenetically corrected regression comparisons
- transformed-tree review around the same primate response surface
- evolutionary-mode fitting, likelihood-ratio reporting, and signal ledgers

What remains intentionally open:

- the intercept-sweep coverage fragment carried as `evidence-010`
- any broader claim that one primate family closes all comparative workflows
  in the repository

This directory exists so the PCM2 study can point reviewers to the exact
reference artifacts without hiding the one remaining open coverage boundary.
